# 捞尸人慢读器

一个只开放当前可读章节的浏览器阅读器。目录只显示已经可读的章节，阅读页只有正文和返回按钮；设置通过右上角齿轮打开，可以调整字号、行距、字型和背景色。

章节数据不会上传到 GitHub。发布到 GitHub Pages 的只有阅读器外壳；手机第一次打开后导入本地 JSON，之后数据保存在手机浏览器里，可以离线读，电脑关闭也不影响。

## 本机运行

```powershell
npm start
```

打开：

```text
http://localhost:4173
```

## 手机使用

1. 打开 GitHub Pages 发布后的网页。
2. 首次进入时选择导出的 `slow-reader-data.json`。
3. 可以把网页添加到手机桌面。

应用按导入当天起算，每天早上 8:00 多开放一章。没有提前阅读入口，也不显示未开放章节标题。

## 数据文件

本机开发用数据放在 `data/app-data.json`。给手机导入的数据放在 `exports/slow-reader-data.json`。这两个目录都被 `.gitignore` 排除，不会提交到 GitHub。
